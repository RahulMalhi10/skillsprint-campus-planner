# 🎓 SkillSprint — Campus Planner

A modern, responsive campus planner designed to help university students organize their academic schedules, assignments, deadlines, and learning goals in one place.

## ✨ Features

- 📊 **Dashboard** — View your academic overview, upcoming tasks, and progress.
- 🗓️ **Weekly Timetable** — Browse your university schedule by day and class.
- 📚 **Course Details** — View course names, timings, instructors, and classrooms.
- ✅ **Task Manager** — Add, edit, complete, delete, and filter tasks.
- 🎯 **Learning Goals** — Track progress toward personal skill-development goals.
- 📥 **CSV Export** — Export timetable information for easy reference.
- 💾 **Local Storage** — Keep tasks and progress saved in your browser.
- 📱 **Responsive Design** — Use the planner on desktop, tablet, or mobile.
- 🌙 **Modern Dark UI** — Enjoy a clean, futuristic dashboard experience.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/RahulMalhi10/skillsprint-campus-planner.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No package installation or build process is required.

## 💾 Data Storage

The application uses browser Local Storage to save tasks and learning progress.

**Note:** Locally stored data is specific to the browser and device. It does not automatically synchronize across devices or browsers.
